HOW TO ADD THIS TO YOUR VITE REACT PROJECT
1. Unzip this folder.
2. Copy the App.jsx, App.css, and index.css files into your project's src folder.
3. Copy the entire components folder into your project's src folder.
4. Make sure src/main.jsx imports "./index.css" and renders <App />. A standard Vite main.jsx already does this.
5. In your terminal, run:
   npm install
   npm run dev
